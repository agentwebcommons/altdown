# Altdown

Altdown is a format for publishing a Markdown copy of a web page next to the page itself.
Its name is short for *Alternate Markdown*.

- **Read the specification:** https://altdown.org/spec/ (as Markdown: https://altdown.org/spec/index.md)
- **This repository** is the specification's source. The website is generated from it.

https://altdown.org/spec/. See [CHANGELOG.md](CHANGELOG.md).

## Feedback

- **Something unclear, wrong or missing in the text:** open an issue. Quote the section and say what you expected.
- **A proposed change to the wording:** open a pull request against `spec/<version>.md`.
- **A broader question or idea:** start a discussion.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how changes are decided.
